# LIAMJ.CA

This is a PHP, React, TypeScript project that showcases my work. It employs Domain-driven Design and Onion architecture patterns to keep the code (and my brain) organised. It started out as a simpler one-page blurb about myself but has grown to include some actually complex little web apps.

My back-end domains live in [/Lib/](Lib/), while my front-end domains live in [/src/](src/). Feel free to poke around. I like [/src/Terminal/](src/Terminal) and [/src/StoneTower/](src/StoneTower/) the most myself.
